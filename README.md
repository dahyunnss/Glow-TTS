# Implementation of Glow-TTS

Our implementation serves as a counterpart model for experiments and research based on the original [Glow-TTS](https://arxiv.org/abs/2005.11129) paper.

This repository provides an implementation of Glow-TTS, a flow-based, fully parallel text-to-speech (TTS) model that generates high-quality speech through monotonic alignment search without relying on an external aligner.
